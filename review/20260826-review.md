## 2. P0 잔존 — Int8 PTQ FloatFunctional 미적용

Hardswish 교체로 `aten::silu.out` 문제는 사라졌지만, **다음 벽이 나왔습니다.**

```
RuntimeError: Int8 모델이 추론 불가 상태입니다. 저장을 중단합니다:
  promoteTypes with quantized numbers is not handled yet;
  figure out what the correct rules should be, offending types: Float QUInt8
```

### 2.1 실패 지점 특정

`QuantStub`을 포함한 래퍼로 블록 단위 격리 테스트를 수행해 **정확한 위치를 확정했습니다.**

| 블록 | 결과 | 원인 |
| :--- | :---: | :--- |
| `ConvModule` (Conv+BN+Hardswish) | ✅ 통과 | — |
| `ConvNeXtBlockNPU` (`residual + gamma*x`) | ❌ | `promoteTypes ... Float QUInt8` |
| `BiFPNBlock` (`p4 + interpolate(p5)` 등) | ❌ | `aten::add.out` 를 QuantizedCPU 에서 실행 불가 |

**근본 원인**: eager-mode 양자화에서는 `+`, `*` 등 산술 연산이 반드시
`torch.ao.nn.quantized.FloatFunctional`을 거쳐야 합니다. 현재 두 모듈이 raw 연산자를 사용합니다.

- `models/backbone.py:20` — `residual + self.drop_path(self.gamma * x)`
  `self.gamma`는 일반 Float `Parameter`이고 `x`는 QUInt8 → **타입 승격 불가**
- `models/neck.py:34-39` — BiFPN 덧셈 4곳(실질 5회)이 전부 raw `+`

### 2.2 수정 코드

```python
# models/backbone.py
from torch.ao.nn.quantized import FloatFunctional

class ConvNeXtBlockNPU(nn.Module):
    def __init__(self, dim, layer_scale_init=1e-6, drop_path=0.0):
        super().__init__()
        ...
        self.gamma = nn.Parameter(layer_scale_init * torch.ones(dim, 1, 1))
        # 양자화 텐서끼리의 산술은 FloatFunctional 을 거쳐야 스케일/제로포인트가 전파됩니다.
        self.gamma_mul = FloatFunctional()
        self.skip_add  = FloatFunctional()

    def forward(self, x):
        residual = x
        x = self.pwconv2(self.act(self.pwconv1(self.norm(self.dwconv(x)))))
        x = self.gamma_mul.mul(x, self.gamma)
        return self.skip_add.add(residual, self.drop_path(x))
```

```python
# models/neck.py
from torch.ao.nn.quantized import FloatFunctional

class BiFPNBlock(nn.Module):
    def __init__(self, channels):
        super().__init__()
        self.td_conv_p4 = DWSepConv(channels)
        self.td_conv_p3 = DWSepConv(channels)
        self.bu_conv_p4 = DWSepConv(channels)
        self.bu_conv_p5 = DWSepConv(channels)
        # 덧셈 지점마다 별도 인스턴스여야 각자의 관측 스케일을 갖습니다.
        self.add = nn.ModuleList([FloatFunctional() for _ in range(5)])

    def forward(self, p3, p4, p5):
        p4_td  = self.td_conv_p4(self.add[0].add(p4, F.interpolate(p5, scale_factor=2.0, mode='nearest')))
        p3_out = self.td_conv_p3(self.add[1].add(p3, F.interpolate(p4_td, scale_factor=2.0, mode='nearest')))
        p4_out = self.bu_conv_p4(self.add[2].add(self.add[3].add(p4, p4_td),
                                                 F.max_pool2d(p3_out, kernel_size=2, stride=2)))
        p5_out = self.bu_conv_p5(self.add[4].add(p5, F.max_pool2d(p4_out, kernel_size=2, stride=2)))
        return p3_out, p4_out, p5_out
```

> ⚠️ `FloatFunctional`은 **덧셈 지점마다 별도 인스턴스**여야 합니다. 하나를 재사용하면 서로 다른 분포의 텐서가 같은 observer를 공유해 스케일이 망가집니다.

### 2.3 함께 처리할 것 — 백본 BN 미fuse

`utils/quantize.py:30-32`가 `ConvModule`만 순회하므로,
`ConvNeXtBlockNPU`의 `dwconv`+`norm` 12쌍과 stem·downsample BN 4개, **총 16개 BatchNorm이 fuse 대상 밖**입니다 (2차 리뷰에서 이미 지적, 미조치).

```python
from models.backbone import ConvNeXtBlockNPU

for module in model_fp32.modules():
    if isinstance(module, ConvModule):
        fuse_modules(module, [['conv', 'bn']], inplace=True)
    elif isinstance(module, ConvNeXtBlockNPU):
        fuse_modules(module, [['dwconv', 'norm']], inplace=True)
# stem / downsamples 의 Conv+BN 도 동일하게 처리
```

### 3.1 🟠 flip이 여전히 boxes 블록 안에 중첩

2차 리뷰 §4-2 지적이 반영되지 않았습니다.
`data/transforms.py:29`의 flip 블록이 아직 `if targets['boxes'].numel() > 0:`(line 25) **안**에 있습니다.
안쪽에 중복 `if`(line 32)만 추가됐고 **블록 위치는 그대로**입니다.

```
p_flip=1.0 으로 20회 시도 → 한 번도 안 뒤집힘   ❌ 미해결
```

박스가 있을 때의 flip 자체는 정확합니다:

```
[0,0,100,100] -> [[540.0, 0.0, 640.0, 100.0]]   (기대 [[540,0,640,100]])  ✅
```

**수정** — 블록을 밖으로 빼기만 하면 됩니다:

```python
image = TF.resize(image, list(self.img_size))
sx, sy = self.img_size[1] / w0, self.img_size[0] / h0
if targets['boxes'].numel() > 0:
    targets['boxes'] = targets['boxes'] * torch.tensor([sx, sy, sx, sy])

# ↓ 들여쓰기를 한 단계 낮춰 박스 유무와 무관하게 수행
if random.random() < self.p_flip:
    image = TF.hflip(image)
    if targets['boxes'].numel() > 0:
        boxes = targets['boxes']
        new_xmin = self.img_size[1] - boxes[:, 2]
        new_xmax = self.img_size[1] - boxes[:, 0]
        boxes[:, 0], boxes[:, 2] = new_xmin, new_xmax
        targets['boxes'] = boxes
```

## 4. 신규 발견 — assigner 성능 회귀

2차 리뷰가 제안한 `REG_RANGES` 코드를 그대로 적용하면서 **파이썬 루프가 학습 경로에 들어왔습니다.**

```python
# utils/loss.py:77-78 — 8400개 원소에 대해 .item() 을 파이썬 루프로 2회
lo = torch.tensor([REG_RANGES[int(s.item())][0] for s in strides], device=device).unsqueeze(1)
hi = torch.tensor([REG_RANGES[int(s.item())][1] for s in strides], device=device).unsqueeze(1)
```

이 함수는 **배치의 이미지마다 호출**됩니다.

```
assigner 1회: 33.4 ms    → batch 16 이면 534 ms/step (순전파·역전파와 별개로)
torch.where 벡터화:  0.099 ms
                     → 약 330배 차이
```

실제로 41 step 오버피팅에 63초가 소요됐습니다. COCO 전체 학습에서는 치명적인 병목이 됩니다.

**수정** — `strides`는 세 값뿐이므로 텐서 연산으로 대체할 수 있습니다.

```python
# 파이썬 루프 없이 레벨별 회귀 범위를 만듭니다. GPU 동기화(.item())도 발생하지 않습니다.
lo = torch.where(strides == 8, 0.0,
     torch.where(strides == 16, 64.0, 128.0)).unsqueeze(1)
hi = torch.where(strides == 8, 64.0,
     torch.where(strides == 16, 128.0, float('inf'))).unsqueeze(1)
in_level = (max_reg >= lo) & (max_reg <= hi)
```

> `.item()`은 CUDA에서 **호스트-디바이스 동기화를 강제**하므로, GPU 학습 시 체감 손해가 CPU보다 더 큽니다.
> 더 나아가 `points`/`strides`/`lo`/`hi`는 해상도가 고정이면 상수이므로, assigner 바깥에서 한 번만 계산해 캐시하는 것이 가장 좋습니다.

### 8-2. Int8 실패 지점 격리 (§2.1)

```python
import torch, torch.nn as nn, warnings
warnings.filterwarnings('ignore')
import torch.ao.quantization as quant
from torch.ao.quantization import QuantStub, DeQuantStub, fuse_modules
from models.backbone import ConvNeXtBlockNPU
from models.neck import BiFPNBlock, ConvModule

class Wrap(nn.Module):
    def __init__(self, inner, multi=False):
        super().__init__()
        self.q, self.inner, self.dq, self.multi = QuantStub(), inner, DeQuantStub(), multi
    def forward(self, *xs):
        xs = [self.q(x) for x in xs]
        out = self.inner(*xs)
        return tuple(self.dq(o) for o in out) if self.multi else self.dq(out)

def check(inner, xs, name, multi=False):
    w = Wrap(inner, multi).eval()
    for m in w.modules():
        if isinstance(m, ConvModule):
            fuse_modules(m, [['conv', 'bn']], inplace=True)
    torch.backends.quantized.engine = "qnnpack"
    w.qconfig = quant.get_default_qconfig("qnnpack")
    p = quant.prepare(w)
    with torch.no_grad(): p(*xs)
    q = quant.convert(p)
    try:
        with torch.no_grad(): q(*xs)
        print(f"  {name}: ✅ 통과")
    except Exception as e:
        print(f"  {name}: ❌ {str(e)[:120]}")

check(ConvNeXtBlockNPU(32), (torch.randn(1,32,32,32),), "ConvNeXtBlockNPU")
check(BiFPNBlock(32), (torch.randn(1,32,32,32), torch.randn(1,32,16,16), torch.randn(1,32,8,8)),
      "BiFPNBlock", multi=True)
check(ConvModule(32, 32, 3, padding=1), (torch.randn(1,32,32,32),), "ConvModule")
```
