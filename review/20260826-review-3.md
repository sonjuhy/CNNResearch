## 2. P0 잔존 — Int8 PTQ, 원인 2개 분리 및 해법 확정

4차에서 제시한 `fold_gamma()` + fuse 확대는 **정확한 수정이었습니다.** 그 결과 이전 에러(`Mul operands should have same data type`)는 사라졌고, 그 뒤에 가려져 있던 **서로 무관한 원인 2개**가 순차적으로 드러났습니다.

### 2.1 원인 (a) — `layer_scale_init=1e-6`이 양자화 스케일을 붕괴시킴

fold 후 `pwconv2` 출력 크기가 극단적으로 작아져, observer가 유효한 스케일을 만들지 못합니다.

**gamma 스윕 실측**:

| gamma | fold 후 `pwconv2` 출력 \|max\| | 결과 |
| :--- | ---: | :--- |
| **1e-6 (현재 초기값)** | 2.482e-07 | ❌ `failed to create QNNPACK Add operator` |
| 1e-3 | 2.482e-04 | ✅ 통과 |
| 1e-1 (학습 후 예상) | 2.482e-02 | ✅ 통과 |
| 1.0 | 2.482e-01 | ✅ 통과 |

**근본 원인은 `utils/quantize.py`가 체크포인트를 로드하지 않는다는 점입니다.**

```
$ grep -n "load_state_dict\|checkpoint" utils/quantize.py
  → 없음. 랜덤 초기화 모델을 양자화하고 있습니다.
```

`utils/quantize.py:38`은 `SOTADetector(scale=scale, quantizable=True)`를 새로 만들 뿐입니다.
PTQ(Post-Training Quantization)는 정의상 **학습 후** 공정인데, 현재는 무작위 가중치를 양자화합니다.
학습된 모델이라면 gamma가 1e-6보다 훨씬 커져 있어 이 문제 자체가 발생하지 않습니다.

```python
# utils/quantize.py — 모델 생성 직후에 추가
model_fp32 = SOTADetector(scale=scale, quantizable=True)

ckpt = f"checkpoints/best_{scale}.pt"
if not os.path.exists(ckpt):
    raise RuntimeError(
        f"PTQ 는 학습된 가중치가 필요합니다: {ckpt} 없음. "
        "무작위 초기화 모델은 LayerScale(1e-6) 때문에 양자화 스케일이 붕괴합니다."
    )
model_fp32.load_state_dict(torch.load(ckpt, map_location='cpu'))
model_fp32.eval()
```

> 보조 방어책으로 `fold_gamma()` 안에서 gamma가 비정상적으로 작을 때 경고를 남기는 것도 좋습니다.
> ```python
> if self.gamma.abs().max() < 1e-4:
>     warnings.warn("gamma 가 초기값 수준입니다. 학습되지 않은 모델을 양자화하고 있을 수 있습니다.")
> ```

### 2.2 원인 (b) — 헤드가 양자화 텐서에 float 연산을 수행

원인 (a)를 우회하고(gamma=0.1로 설정) 다시 돌리면 **두 백엔드 모두** 동일한 에러가 납니다.

```
qnnpack: ❌ promoteTypes with quantized numbers is not handled yet;
            offending types: QUInt8 Float
fbgemm : ❌ (동일)
```

`models/head.py:73`이 원인입니다.

```python
reg = ((reg_out.flatten(2).permute(0, 2, 1) * scale).clamp(max=8.0)).exp() * stride
#                                            ↑ Float Parameter × QUInt8 텐서
```

- `self.scales`는 일반 Float `Parameter`이고 `reg_out`은 양자화 Conv 출력(QUInt8)입니다
- `.exp()`도 양자화 커널이 존재하지 않습니다
- `models/detector.py:41`의 `dequant`은 **헤드가 끝난 뒤**에 적용되므로, 이 연산들은 양자화 도메인 안에서 실행됩니다

**해법**: 헤드의 conv 출력 직후 float 도메인으로 복귀시킵니다. conv 자체는 양자화 이득을 그대로 누리고, 스케일·지수 연산만 float으로 처리됩니다.

```python
# models/head.py — SOTAHead.__init__ 에 추가
from torch.ao.quantization import DeQuantStub
self.dequant = DeQuantStub()      # 비양자화 경로에서는 항등 함수로 동작

# SOTAHead.forward 안에서
for feat, head, stride, scale in zip(features, self.heads, self.strides, self.scales):
    cls_out, reg_out, obj_out = head(feat)

    # 여기서 float 도메인 복귀 — 이후 * scale / clamp / exp 는 전부 float 연산
    cls_out = self.dequant(cls_out)
    reg_out = self.dequant(reg_out)
    obj_out = self.dequant(obj_out)

    cls_list.append(cls_out.flatten(2).permute(0, 2, 1))
    obj_list.append(obj_out.flatten(2).permute(0, 2, 1))
    reg_list.append(((reg_out.flatten(2).permute(0, 2, 1) * scale).clamp(max=8.0)).exp() * stride)
```

> `models/detector.py:40-41`의 기존 dequant 분기는 헤드가 이미 float을 반환하므로 제거하거나 그대로 두어도 무해합니다(항등).

### 2.3 두 수정을 적용한 검증 결과

```
=== 헤드 conv 직후 DeQuantStub 삽입 + gamma 정상값 ===
  qnnpack: ✅ Int8 추론 성공  cls=(1, 8400, 80)  state_dict=7.02 MB
  fbgemm : ✅ Int8 추론 성공  cls=(1, 8400, 80)  state_dict=7.36 MB
```

| 항목 | 값 |
| :--- | :--- |
| FP32 state_dict | 22.63 MB |
| Int8 state_dict (qnnpack) | **7.02 MB (69% 절감)** |
| 출력 형태 | `cls (1, 8400, 80)` — 정상 |
| 백엔드 호환 | qnnpack ✅ / fbgemm ✅ |

**남은 작업은 §2.1·§2.2 패치 2개뿐입니다.** 적용하면 S7이 통과해 14/14가 됩니다.

if args.config:
    cfg = yaml.safe_load(open(args.config))

            setattr(args, k, v)

**진단이 깨끗하게 끝난 라운드입니다.**

Int8 PTQ는 다섯 번의 리뷰에 걸쳐 에러가 계속 바뀌었습니다 —
`quantized::conv2d.new` → `aten::silu.out` → `promoteTypes(Float QUInt8)` → `Mul operands` → `QNNPACK Add` / `QUInt8 Float`.
겉보기에는 제자리걸음 같지만, 실제로는 **양자화 그래프를 입구에서 출구까지 한 겹씩 벗겨 온 과정**이었습니다.
이번에 마지막 두 겹(학습되지 않은 가중치 · 헤드의 float 연산)이 드러났고, 둘 다 수정본으로 **qnnpack·fbgemm 양쪽 통과를 확인**했으므로 더 이상 숨은 층은 없습니다.

`LICENSE`·`configs`·`CODE_REVIEW.md`도 이번에 정리되면서, 1차부터 지적한 **"파일은 만들었지만 내용이 유효하지 않은"** 상태가 모두 해소됐습니다.

### 6-1. gamma 스윕 — 원인 (a) 재현 (§2.1)

```python
import torch, warnings
warnings.filterwarnings('ignore')
import torch.nn as nn, torch.ao.quantization as quant
from torch.ao.quantization import QuantStub, DeQuantStub, fuse_modules
from models.backbone import ConvNeXtBlockNPU

class W(nn.Module):
    def __init__(self, blk):
        super().__init__(); self.q, self.b, self.dq = QuantStub(), blk, DeQuantStub()
    def forward(self, x): return self.dq(self.b(self.q(x)))

def run(gamma_val, label):
    torch.manual_seed(0)
    blk = ConvNeXtBlockNPU(32).eval()
    with torch.no_grad(): blk.gamma.fill_(gamma_val)
    blk.fold_gamma()
    fuse_modules(blk, [['dwconv', 'norm']], inplace=True)
    x = torch.rand(1, 32, 16, 16)
    with torch.no_grad():
        h = blk.pwconv2(blk.act(blk.pwconv1(blk.norm(blk.dwconv(x)))))
    m = W(blk).eval()
    torch.backends.quantized.engine = "qnnpack"
    m.qconfig = quant.get_default_qconfig("qnnpack")
    p = quant.prepare(m)
    with torch.no_grad(): p(x)
    q = quant.convert(p)
    try:
        with torch.no_grad(): q(x); r = "✅"
    except Exception as e: r = f"❌ {str(e)[:50]}"
    print(f"  {label:28s} |max|={h.abs().max().item():.3e} -> {r}")

for g, lbl in [(1e-6, "gamma=1e-6 (현재 초기값)"), (1e-3, "gamma=1e-3"),
               (1e-1, "gamma=1e-1 (학습 후)"), (1.0, "gamma=1.0")]:
    run(g, lbl)
```

### 6-2. 전체 모델 Int8 — 두 수정 적용 시 통과 확인 (§2.3)

```python
import torch, io, warnings
warnings.filterwarnings('ignore')
import torch.ao.quantization as quant
from torch.ao.quantization import fuse_modules
from models.detector import SOTADetector
from models.neck import ConvModule
from models.backbone import ConvNeXtBlockNPU

def build(backend):
    torch.manual_seed(0)
    m = SOTADetector(scale='nano', quantizable=True).eval()
    # (a) 대용: 학습된 가중치 대신 gamma 를 현실적인 값으로. 실제로는 load_state_dict 사용
    with torch.no_grad():
        for mod in m.modules():
            if isinstance(mod, ConvNeXtBlockNPU): mod.gamma.fill_(0.1)
    for mod in m.modules():
        if isinstance(mod, ConvModule):
            fuse_modules(mod, [['conv', 'bn']], inplace=True)
        elif isinstance(mod, ConvNeXtBlockNPU):
            mod.fold_gamma(); fuse_modules(mod, [['dwconv', 'norm']], inplace=True)
    fuse_modules(m.backbone.stem, [['0', '1']], inplace=True)
    for ds in m.backbone.downsamples:
        fuse_modules(ds, [['0', '1']], inplace=True)
    torch.backends.quantized.engine = backend
    m.qconfig = quant.get_default_qconfig(backend)
    p = quant.prepare(m)
    with torch.no_grad():
        for _ in range(2): p(torch.rand(2, 3, 640, 640))
    return quant.convert(p)

# ※ models/head.py 에 DeQuantStub 을 넣은 뒤 실행해야 통과합니다 (§2.2)
for backend in ["qnnpack", "fbgemm"]:
    q = build(backend)
    with torch.no_grad(): out = q(torch.rand(1, 3, 640, 640))
    b = io.BytesIO(); torch.save(q.state_dict(), b)
    print(f"  {backend}: ✅ cls={tuple(out['cls'].shape)} state_dict={b.tell()/1e6:.2f}MB")
```
